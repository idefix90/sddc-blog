How to deploy and configure VCF Installer 9.0.2

Deployment:

Download VCF Installer from https://support.broadcom.com

e.g. https://support.broadcom.com/group/ecx/productfiles?subFamily=VMware%20Cloud%20Foundation&displayGroup=VMware%20Cloud%20Foundation%209&release=9.0.2.0&os=&servicePk=537791&language=EN

  • Connect to your vCenter Web UI

  • Right-click your cluster and select “Deploy OVF Template” from the context menue.

  • Click on “Local file” and then on “UPLOAD FILES”

  • Browse to your Download folder, select the .ova template and click “Open”

  • Proceed by clicking “NEXT”

  • Select your compute resource für your Installer and click “NEXT”

  • Review details and proceed with “NEXT”

  • Accept the License afreements an click “NEXT”

  • Select the datastore where you ant to install your VM and proceed with “NEXT”

  • Select the network of your choice and click “NEXT”

  • Customize the Template by filling out the required fields like hostname, NTP and passwords, proceed with “NEXT”

    • root user Password
    • local user password
    • Host Name
    • NTP Servers
    • Network 1 IP Address
    • Network 1 Subnet Mask
    • Network Default Gateway
    • DNS Domain Name
    • Domain Search Path
    • Domain Name Servers

  • Review the “Ready to complete” page and start the Deployment with “FINISH”

Configuration:

After successfully deploying the appliance, you must do some minor configurations regarding the depot settings.

The VCF Installer has no binaries für vCenter, ESX and other components included. After configuring the depot settings, VCF Installer can download the required binaries from either an online or an offline depot.

  • Login into VCF Installer with user admin@local and the password you have specified earlier.

  • To configure your depot settings, click on “DEPOT SETTINGS AND BINARY MANAGEMENT”

    Now, you have 2 Options!

  1. Connect to the online depot – Download binaries directly from Broadcom.com

  2. Offline Depot – Download binaries from an internal web server (good for dark sites)

    You have to decide, which option you prefer, you cannot use both!

  • Option 1: Connect to the online depot

    First, click on “CONFIGURE” to start the configuration for the online depot configuration.

  • You must specify the Broadcom download token – proceed with “AUTHENTICATE”

    Optionally you can configure proxy and proxy authentication settings für accessing the internet.

  • After successfully completing the configuration, you should see something like this.

  • Option 2: Connect to an offline depot

Click on “CONFIGURE” to start the configuration for the offline depot configuration.

  • Fill out the form and click “CONFIGURE”

    FQDN or IP Address – FQDN or IP Adress of your internal WEB Server

    Port – WEB Server port

    Username – WEB Server Username für accessing the internal depot

    Password – WEB Server Password

    For more Information, how too setup an internal depot server, please visit:

    https://knowledge.broadcom.com/external/article/312168/vcf-offline-depot-deployment.html

  • After successfully completing the configuration, you should see something like this.

Downloading the required sources from your depot:

  • Now you must specify the binaries for downloading. Scroll down to the “Binary Management” area and select the product and version you want.

  • Make your choice and click “DOWNLOAD”

  • Wait until the download status for each component is “Success”

  • Now you are ready to deploy a new or import an existing environment.

    At the very top of the page, you can find the “< RETURN HOME” Link.

    To start a new deployment or import a existing vSphere environment, start the “DEPLOYMENT WIZARD” and follow the instructions.
